# Приёмка — демо для маслозавода

Демо системы приёмки семечки: три приложения на общей базе и push-уведомления на телефон.
Данные вымышленные: маслозавод «Пример», хозяйства «Рассвет», «Заря» и другие.

| Приложение | Для кого | Где |
|---|---|---|
| **Рабочее место** `docs/desk/` | Весовая: очередь (канбан), ручной ввод веса, анализ, журнал, базис, сотрудники и роли | Компьютер |
| **Руководитель** `docs/owner/` | Сводка смены, очередь, поставщики, push о важном | Телефон (PWA) |
| **Водитель** `docs/driver/` | Запись на выгрузку, место в очереди, push «ваша очередь» | Телефон (PWA) |

## Как устроено
```
Телефон / ПК  ──  сайт на GitHub Pages (docs/)
      │  HTTPS
      ▼
ngrok-туннель  ──▶  Node-сервер на ПК (server/)  ──▶  SQLite (data/priemka.db)
      ▲
push ◀── сервисы Apple / Google ◀── web-push (server/push.js)
```
- **Сайт** — статические файлы в `docs/`, публикуются GitHub Pages. Все пути относительные.
- **Сервер** — Node.js без фреймворков: API, вход, права, живые обновления (поток событий), push.
- **База** — SQLite через `better-sqlite3`. Первый запуск заполняет её: 10 прошлых дней приёмки, сегодняшняя очередь, записи на завтра, 4 сотрудника.
- **Туннель** ngrok даёт серверу на ПК публичный HTTPS-адрес — он нужен и GitHub Pages, и push на телефоне.

## Запуск
Нужен Node.js 18+ и [ngrok](https://ngrok.com) (бесплатный аккаунт).

```bash
npm install
npm start          # сервер: http://localhost:4321 (сайт открывается и локально)
npm run tunnel     # в другом окне: HTTPS-туннель к серверу
```

### Постоянный адрес туннеля (один раз)
Бесплатный ngrok даёт **один постоянный домен** на аккаунт: dashboard.ngrok.com → Domains → «Create domain».
Дальше запускайте туннель с ним и пропишите его сайту:
```bash
ngrok http 4321 --url=https://ВАШ-ДОМЕН.ngrok-free.app
npm run set-api -- https://ВАШ-ДОМЕН.ngrok-free.app   # записывает адрес в docs/shared/config.js
git commit -am "Адрес сервера демо" && git push
```

### GitHub Pages
Settings → Pages → Source: «Deploy from a branch» → Branch: `main`, папка `/docs`.
Сайт: `https://bogdalleksss.github.io/maslozvddemo/`

## Уведомления на iPhone
1. Откройте в Safari `…/maslozvddemo/owner/` или `…/driver/` (iOS 16.4+).
2. «Поделиться» → «На экран Домой».
3. Откройте приложение **с иконки**, войдите, нажмите «Включить уведомления».

| Приложение | Что приходит |
|---|---|
| Водитель | «Проезжайте на весовую», «Выгрузка: яма №2», «Приёмка завершена, зачётный вес» — только по своим машинам |
| Руководитель | Машина ждёт больше 90 мин, влажная партия, исправлен вес, изменён базис |

## Безопасность
- Пароли — хеш scrypt с солью. Временный пароль нового сотрудника показывается один раз.
- Вход по токену в заголовке `Authorization`: сайт (github.io) и сервер (ngrok) на разных доменах, а Safari блокирует cookie между сайтами. В базе хранится только хеш токена, срок жизни 12 часов, отзыв при отключении сотрудника или смене роли.
- Токен лежит в `localStorage` — компромисс этой схемы. Компенсация: строгая CSP без встроенных скриптов (`script-src 'self'`), без сторонних скриптов.
- Права проверяются на сервере при каждом действии (`PERMS` в `server/server.js`). Водитель получает только свои рейсы — защита от IDOR.
- CORS: к API допускаются только `bogdalleksss.github.io` и localhost.
- Ограничение попыток: 5 неудачных паролей на телефон, 30 на адрес за 10 минут; SMS-код — 3 запроса, 5 попыток, 5 минут жизни.
- Push отправляется только после успешной записи в базу. Ключи VAPID создаются при первом запуске и хранятся в базе, не в git.
- Журнал действий: кто, что и когда (включая исправления веса) — Рабочее место → Сотрудники.

## Ограничения демо
- Демо-пароли общеизвестны: пока туннель включён, войти может любой, кто знает адрес. Не храните здесь реальные данные.
- Сервер работает, пока включён компьютер и запущены `npm start` + туннель.
- Весы — ручной ввод; SMS не отправляются.
- Для продукта: HTTPS-сервер в РФ, PostgreSQL, cookie `HttpOnly; Secure` на одном домене, реальные SMS, двухфакторный вход руководителя.

## Структура
```
docs/            сайт (GitHub Pages)
  index.html     главная демо
  desk/          рабочее место
  owner/         приложение руководителя (PWA: manifest, sw.js)
  driver/        приложение водителя (PWA: manifest, sw.js)
  shared/        стили, общая логика, push, Service Worker, config.js
  icons/         иконки из логотипа (npm run icons)
server/          сервер: server.js (API), db.js (SQLite, заполнение), push.js (Web Push)
tools/           генератор иконок, подстановка адреса туннеля
```
